# 팀장님이 온다 — 3D FPS 도주 에디션

> ⚠ 사내 위험 알림 ⚠
> 진짜로 도망쳐야 한다.

## 만들게 된 사연

원래 잡코리아 바이브톤에 **"팀장님만 보면 한숨 나오는 서비스"**라는 주제로 내보려고 혼자 뚝딱뚝딱 만들어본 프로젝트입니다. 그런데 정작 바이브톤 선정에서는 미끄러졌습니다. 팀장님한테 쫓기는 것도 서러운데 선정에서도 도망쳐버리다니.

만들어놓은 게 아까워서(그리고 도망치는 재미는 진짜 있어서) 혼자 접어두기엔 아쉬워 이렇게 올립니다.

## 뭐 하는 게임인가

1인칭 FPS로 사무실 안에서 팀장님(들)을 피해 끝까지 살아남는 게임입니다. 모드는 두 가지.

- **5살 팀장님 모드** — 키는 작아졌지만 직급은 그대로인 팀장님 한 명이 떼쓰면서 전속력으로 쫓아옵니다. 한 명이지만 빠릅니다.
- **5명의 팀장님 모드** — 사무실 곳곳에서 다섯 명이 동시에 따라붙습니다. 회의실로 숨어도 소용없습니다.

메인 복도, 십자 교차로, 회의실, 휴게실, 대형 오픈 회의실, 큐비클존까지 이어지는 오피스 맵을 뛰어다니며 정해진 시간을 버티면 칼퇴/생존, 붙잡히면 그대로 결과 화면행입니다.

### 조작

| 키 | 동작 |
|---|---|
| W/A/S/D, 방향키 | 이동 |
| 마우스 | 시점 회전 (클릭 시 포인터 잠금) |
| Shift | 스프린트 |
| Space | 점프 |
| R | 시점 정면으로 초기화 |

## 기술 스택

- [Three.js](https://threejs.org/) r0.155.0 (CDN)
- 순수 JS / HTML / CSS, 별도 빌드 도구 없음

## 실행 방법

정적 파일이라 빌드가 필요 없습니다. 다만 Pointer Lock API 때문에 `file://`로 바로 열기보다는 로컬 서버로 여는 걸 추천합니다.

```bash
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080` 접속.

## 파일 구조

- `index.html` — 타이틀/모드선택/커스터마이징/게임/결과 화면 UI 전체
- `character.js` — 팀장님 3D 캐릭터 빌더 (헤어/옷/표정/소품/피부 커스터마이징)
- `world.js` — 오피스 맵 빌더 + 충돌 처리
- `game3d.js` — 화면 전환, 3D 커스터마이징 미리보기, 1인칭 컨트롤, 추격 AI, HUD, 결과 화면
