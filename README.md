# 팀장님이 온다 — 3D FPS 도주 에디션

> ⚠ 사내 위험 알림 ⚠
> 진짜로 도망쳐야 한다.

## 만들게 된 사연

원래 잡코리아 바이브톤에 **"팀장님만 보면 한숨 나오는 서비스"**라는 주제로 내보려고 혼자 뚝딱뚝딱 만들어본 프로젝트입니다. 그런데 정작 바이브톤 선정에서는 미끄러졌습니다. 팀장님한테 쫓기는 것도 서러운데 선정에서도 도망쳐버리다니.

만들어놓은 게 아까워서(그리고 도망치는 재미는 진짜 있어서) 혼자 접어두기엔 아쉬워 이렇게 올립니다.

## 뭐 하는 게임인가

1인칭 FPS로 사무실 안에서 팀장님(들)을 피해 끝까지 살아남는 게임입니다. 모드는 두 가지.

- **5살 팀장님 모드** — 키는 작아졌지만 직급은 그대로인 팀장님 한 명이 떼쓰면서 전속력으로 쫓아옵니다. 한 명이지만 빠릅니다.
- **5명의 팀장님 모드** — 사무실 곳곳에서 다섯 명이 동시에 따라붙습니다. 회의실로 숨어도 소용없습니다.

당신은 신입이고 가진 건 식은 커피 한 잔뿐입니다. 하지만 팀장님 위에는 사장님이 있습니다. 이 게임의 필살기는 권력을 쓰는 게 아니라 더 큰 권력을 빌리는 것이고, 빌린 권력에는 이자가 붙습니다.

접수대와 라운지, 카펫 업무 구역 4개, 유리 회의실 2개, 창가 팬트리로 이어지는 사무실을 뛰어다니며 정해진 시간을 버티면 칼퇴/생존, 붙잡히면 그대로 결과 화면행입니다.

### 조작

| 키 | 동작 |
|---|---|
| W/A/S/D, 방향키 | 이동 |
| 마우스 | 시점 회전 (클릭 시 포인터 잠금) |
| Shift | 스프린트 |
| Space | 점프 |
| 좌클릭 / F | 커피 쏟기: 전방 4.8m 원뿔 안의 팀장님을 3초 멈춤, 재사용 5.5초 |
| Q | 사장님 호출 (궁극기): 게이지가 다 차야 발동 |
| Esc | 일시정지 (화면 클릭으로 재개) |
| R | 시점 정면으로 초기화 |

#### 사장님 호출

이 게임의 유일한 필살기입니다. 게이지가 다 차면 사내 방송이 나가고 사장님이 직접 나타납니다. 다만 결과는 모드마다 다릅니다.

**5명 모드** — 팀장님들은 사장님이 누군지 정확히 압니다. 추격을 버리고 당신이 바라보는 회의실로 뛰어 들어가 줄지어 섭니다. 사장님은 문 앞에 서 있고, 문이 닫힙니다.

**5살 모드** — 다섯 살은 사장님이 누군지 모릅니다. "안경 내놔!!" 하면서 사장님한테 달려들고, 사장님은 복도 반대편으로 도망칩니다. 둘이 붙어 있는 동안이 당신의 시간입니다.

- **조준해서 씁니다.** 5명 모드에서는 바라보는 회의실로 소집됩니다. 엉뚱한 쪽을 보고 누르면 그쪽으로 다 몰려옵니다.
- **발동 중에는 붙잡히지 않습니다.** 끝날 때까지가 도망칠 시간입니다.
- **대가가 영구적입니다.** 끝나고 나온 팀장님은 남은 시간 내내 더 빠릅니다. 한 번 부를 때마다 1.35배씩 누적되고 2.2배에서 멈춥니다.
- **게이지는 위험할수록 빨리 찹니다.** 팀장님이 가까이 붙어 있을 때 더 빠르게 충전됩니다.

클릭해서 마우스를 잠그면 추격과 타이머가 시작됩니다. 시점을 어느 방향으로 돌려도 W/↑는 새 정면, A/D는 해당 시점의 좌우입니다. 위아래 시선은 이동 속도에 영향을 주지 않습니다. Shift 질주는 체력을 사용하며, 소진 시 일정량을 회복한 뒤 다시 사용할 수 있습니다.

### 조작과 연출 개선

- 시점 기준 이동, 짧은 가감속, 대각선 속도 정규화, 프레임 속도에 독립적인 이동량
- 벽 미끄러짐과 작은 이동 단계로 충돌 처리, 점프는 누를 때 한 번씩
- 질주 시 작은 FOV 변화, 수평을 유지하는 카메라, 커피를 든 1인칭 손
- 절차적으로 조형한 얼굴·머리·의상, 곡면을 따라가는 셔츠·라펠, 팔꿈치·무릎 애니메이션
- 성인과 별도로 조정한 아동의 머리·팔·다리 비율, 5종 헤어·4종 표정·5종 소품·4종 피부 (아동은 유치원복 고정)
- 목재 바닥·카펫, 모니터 화면, 사무용 의자, 유리 회의실 출입구와 순환 동선, 실시간 그림자와 바닥 접촉 음영
- 바닥·러그·접촉 음영을 서로 다른 높이에 배치해, 걸을 때 카펫이 검게 일렁이던 z-fighting 제거
- 동일한 충돌 데이터를 사용하는 공유 경로 탐색: 적이 책상과 회의실 벽을 우회하며, 유리벽 너머에서는 붙잡히지 않음
- 소집 중에는 같은 경로 탐색이 플레이어 대신 회의실(5명) 또는 사장님(5살)을 목표로 삼아 전원이 이동
- 건축물·의자·식물을 InstancedMesh로 묶어 반복 오브젝트의 드로콜 절감
- 체력·커피·궁극기 게이지 HUD와 소집 컷인, 마우스 잠금 해제 및 창 전환 시 일시정지

빌드 도구 없이 이동/충돌 회귀 테스트를 실행할 수 있습니다 (Node.js 필요).

```bash
node --test tests/movement.test.cjs tests/navigation.test.cjs tests/traversal.test.cjs tests/coffee.test.cjs tests/summon.test.cjs
```

> `node --test tests/`처럼 디렉터리 전체를 지정하면 Playwright가 필요한 `tests/browser.cjs`까지 실행하려다 실패한다. 파일을 명시해서 돌린다.

## 기술 스택

- [Three.js](https://threejs.org/) r0.155.0 (CDN)
- 순수 JS / HTML / CSS, 별도 빌드 도구 없음

## 실행 방법

정적 파일이라 빌드가 필요 없습니다. 다만 Pointer Lock API 때문에 `file://`로 바로 열기보다는 로컬 서버로 여는 걸 추천합니다.

```bash
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080` 접속.

## 파일 구조

- `index.html` — 타이틀/모드선택/커스터마이징/게임/결과 화면 UI 전체
- `character.js` — 팀장님 3D 캐릭터 빌더 (헤어/옷/표정/소품/피부 커스터마이징)
- `world.js` — 오피스 맵 빌더 + 충돌 처리
- `navigation.js` — 공유 역방향 경로 탐색과 반경을 고려한 직선 시야 검사
- `assets/characters/` — 인체 메시 데이터와 피부 텍스처 ([출처·CC0·변경 내역](assets/NOTICE.md))
- `tools/build-human.py` — 인체 데이터 재생성 도구
- `movement.js` — 시점 기준 이동과 프레임 독립 가감속·체력 계산
- `traversal.js` — 점프와 가구 위 착지 등 높이 처리
- `coffee.js` — 커피 쏟기의 원뿔 판정과 시야 차단 검사
- `summon.js` — 사장님 호출의 게이지·회의실 조준·소집 단계 진행
- `game3d.js` — 화면 전환, 3D 커스터마이징 미리보기, 1인칭 컨트롤, 추격 AI, HUD, 결과 화면


## 브라우저 검증

선택 설치한 Playwright와 Chrome으로 실행한다. 게임 자체에는 npm 설치나 빌드가 필요 없다.

```bash
npm install --prefix /tmp/boss-baby-qa playwright
NODE_PATH=/tmp/boss-baby-qa/node_modules node tests/browser.cjs full
```

기본 Chrome 경로는 macOS이다. 다른 환경에서는 `CHROME_PATH`와 `QA_OUTPUT`을 지정한다.
`visual`은 두 체형과 사무실 여러 각도, `gallery`는 커스터마이징별 화면도 저장한다.
`fullgallery`는 전체 검사와 옵션 촬영, `perf`는 정지 장면의 렌더 처리량 측정이다.
최종 실행 기록과 한계는 [검증 보고서](docs/qa/verification.md)를 참고한다.
`full`은 UI 옵션 선택, 실제 카메라 기준 이동 비교, 두 모드의 입력·Q·ESC·패배·재시작·승리 전환을 검사한다.
시험 중 위치 배치와 타이머 경계값은 응답 가로채기로 브라우저 메모리에만 주입한다.
배포 소스에는 디버그 조작 API가 없다. 승리 경계 테스트는 42/50초 전체 생존 플레이를 대신하지 않는다.

## 현재 표현 범위

캐릭터는 실행 시점에 절차적으로 조형한다. 얼굴·머리·의상 모두 코드가 만든 단면 메시이며
외부 인체 스캔이나 모션 캡처를 쓰지 않는다. 상용 FPS의 스킨드 의상, 손가락 IK,
정교한 표정 리깅 수준은 아니다. 모바일 터치 조작은 지원하지 않는다.
Three.js CDN을 사용하므로 최초 실행에는 인터넷 연결이 필요하다.

`assets/characters/`의 인체 데이터는 이전 버전이 쓰던 것으로, 현재 `index.html`은 불러오지 않는다.
출처 기록을 위해 저장소에는 남겨두되 배포에서는 제외한다.
