# Character asset provenance

The head and hand topology, morph targets, and skin image originate from the
MakeHuman Community **core assets**, released under **CC0 1.0 Universal**.
MakeHuman's application source license (AGPL) is separate; no application source
is included in these character assets.

- Asset license: https://static.makehumancommunity.org/about/license.html
- CC0 deed: https://creativecommons.org/publicdomain/zero/1.0/
- Base topology: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/3dobjs/base.obj
- Adult morph: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/targets/macrodetails/asian-male-young.target
- Child morph: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/targets/macrodetails/asian-male-child.target
- Skin texture: https://download.tuxfamily.org/makehuman/assets/1.1/base/skins/textures/young_lightskinned_male_diffuse3.png

## Included files and modifications

- `characters/human.js`: generated by `tools/build-human.py`. Applies the male
  young/child target to the base topology, scales to metres, extracts visible
  head/neck and hand faces and original UVs, triangulates the polygons, and
  exports eye-joint coordinates. Hidden helper geometry is excluded. Runtime
  code further adjusts expressions, head proportions, scalp/hair and hand pose.
- `characters/skin.png`: the downloaded `young_lightskinned_male_diffuse3.png`,
  renamed for this project. Runtime skin tints are material multipliers.
- Clothing, props, office geometry, procedural wood/carpet/plaster textures,
  animations and navigation are generated by this project's JavaScript, not
  assets taken from MakeHuman application source.

Rebuild topology (supply downloaded inputs; no network access in the script):

```sh
python3 tools/build-human.py base.obj asian-male-young.target asian-male-child.target
```

The extracted child asset uses the same core male skin image. It is a stylized
child character, not a scan of a particular person. No external skeleton or
motion-capture animation is included.
