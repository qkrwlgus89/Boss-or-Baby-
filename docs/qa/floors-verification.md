# 층별 야근 진행 검증 — 2026-09-26

기존 문제: 플레이어 걷기 5.6 대비 성인 추격 기본 속도 2.6~3.0. 야근 모드는 120초 단위의 완만한 가속이 있었으므로 엄밀히 무한 안전은 아니지만, Q를 피하며 반복 이동하는 구간이 길었다. Q 종료에 승진이 연결돼 있고 공간 목표가 없었다.

변경: 결재 2곳 → 엘리베이터 호출 → 7초 추격 대기 → E 탑승 → 2.2초 전환 → 승진. 세 가지 공통 사무실 변형이 순환하며 결재 위치와 중앙 수납장 통로가 달라진다. 완전히 독립된 세 건물은 아니다. 65초 후 생존 점수 적립 중단 및 증원, 이후 15초마다 최대 4차 증원. Q와 무관하게 시간 가속이 적용된다.

검증 결과:

- 순수 로직 테스트 37개 통과: 층 진행 게이트·거리·높이·체류 압박·초기화, 기존 이동·충돌·경로 탐색·커피·Q·직급.
- Chrome 층 통합 검사 통과: 4회 연속 승진, 세 배치의 두 결재대와 엘리베이터까지 실제 충돌 맵 경로 탐색, 인원 증가, Q 승진 제거, 초과 체류 증원, 일반 모드 복귀, 재시작 초기화, ESC 시간 정지. JS 오류 없음.
- 기존 전체 Chrome 검사 통과: 커스터마이징 51개 선택, 실제 사무실 경로, 카메라 이동, 양 모드 Q·포인터 잠금·점프·일시정지·패배·승리·재시작. JS/HTTP 오류 없음.
- 내장 브라우저 도구는 sandboxPolicy 메타데이터 오류로 연결되지 않아 기존 Playwright/Chrome 검사 환경 사용.

자동화는 경계값을 HTTP 응답의 테스트 전용 훅으로 주입한다. 배포 코드에 디버그 API는 없다. 경로와 전환은 검증했지만, 사람의 실제 플레이로 층별 완료율이나 평균 생존 시간을 측정한 것은 아니다. 속도·65초 체류 기준·7초 엘리베이터 대기는 플레이 피드백에 따라 조정할 초기 값이다.

결재 NPC 보완: 층마다 추격하지 않는 담당자 2명, 서류·도장 창구, 대기/완료 말풍선, 가까이 갔을 때 중앙 E 제출 안내 추가. 기존 수납장에 가리지 않도록 서쪽 창구 위치를 조정했다. 층별 경로 및 완료 상태, 모드 변경 시 NPC 제거, 실제 E 키 결재를 Chrome에서 확인했다.
