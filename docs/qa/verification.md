# 사무실 리빌드 검증 — 2026-09-22

## 변경 범위

- 기존 yaw 기준 FPS 이동은 유지했다. 정장 소매·바지 면 방향, 몸통을 뚫던
  셔츠/라펠, 어깨 끝의 열린 면, 얼굴 조명을 수정했다.
- 아동은 다리와 팔 길이, 머리 비율을 따로 조정했다. 헤어 실루엣과 눈썹을
  보정하고 1인칭 손을 피부 UV가 있는 인체 메시로 교체했다.
- 회의실 중앙 복도 쪽 2m 출입구, 안내 포털, 모니터 화면, 가구 접촉 음영,
  천장 재질과 창가 방향광을 적용했다. 반복 의자/식물까지 인스턴싱했다.
- 충돌 정보를 공유하는 역방향 경로 탐색으로 회의실과 가구를 우회한다.
  시야가 막히면 벽 너머에서 붙잡지 않는다. Q의 기존 20cm 간격 샘플링이 4cm 유리벽을 놓치던 버그를
  정확한 선분/박스 교차 검사로 수정했다.

## 실행 환경과 검증 방법

macOS / Chrome / Three.js r155 / 1440×900 / DPR 1.
최종 GPU는 `ANGLE Metal Renderer: Apple M4`였다.
내장 브라우저 연결은 `missing field sandboxPolicy` 오류로 실패해 기존
Playwright + Chrome 경로를 사용했다. 초기 검사는 SwiftShader였고,
최종 통합/성능 검사는 Chrome 기본 Metal 렌더러로 수행했다.

`tests/browser.cjs`는 테스트에서만 `game3d.js` 응답을 가로채 상태 관찰과
시나리오 위치/타이머 설정을 추가한다. 게임에 디버그 API를 저장하지 않는다.
화면 캡처 때만 일시정지 안내를 숨기며 제품 UI는 유지한다.

## 통과 항목

- Node 이동/충돌 5개 + 경로 탐색/얇은 유리벽 5개 = **10개**.
- 실제 Three.js 카메라와 이동 방향 비교: yaw 5종 × pitch 3종 × 입력 3종 = **45개**.
- 커스터마이징 UI **41개 선택**: 성인 23개, 아동 18개(유치원복 고정).
  이는 각 옵션 검사이며 모든 조합의 전수검사는 아니다. 전 옵션 화면도 촬영했다.
- 실제 사무실 경로 **5개**: 두 회의실, 책상 사이, 팬트리, 업무 구역.
  이동 구간마다 충돌 반경을 검사했고 목적지 0.7m 이내에 도달했다.
- 두 모드: 포인터 잠금, Q, ESC 타이머 정지, 패배, 재시작, 승리 전환.
  공통 컨트롤러의 W 이동·마우스 회전·R 초기화·점프·Shift 체력 소비도 검사했다.
- 성인 모드: 유리벽 뒤 포획 차단, 벽을 향해 걸을 때 통과 차단, 벽 뒤 Q 차단.
- 커스터마이징 뒤 루트 컨테이너가 가로 스크롤되던 문제를 `overflow: clip`으로
  수정하고 게임 캔버스의 왼쪽 좌표가 0인지 확인했다.
- JavaScript 예외 **0건**, HTTP 400 이상 응답 **0건**.
- JavaScript 구문 검사 및 `git diff --check` 통과.

승리는 테스트가 타이머를 종료 직전으로 설정해 전환을 검사했다.
42/50초 전체를 직접 살아남은 플레이 기록이 아니며, 난이도 균형을 입증하지 않는다.

## 렌더링 수치

- 월드 충돌체 97개, 월드 인스턴스 배치 57개.
- 업무 구역을 보는 특정 각도: 60 draw calls / 약 56,292 triangles.
- 다섯 적을 바라보는 정지 장면: **약 60.0fps**, 프레임 시간 p95 **16.7ms**,
  296 draw calls. 워밍업 후 120프레임을 측정했다.
- 이 측정은 정지 장면의 렌더 처리량이다. 추격·탐색·입력이 함께 실행되는
  전체 플레이 벤치마크나 다른 GPU 성능 보장은 아니다.

## 시각 검토와 남은 한계

이전 화면의 뒤집힌 소매·바지와 몸통을 관통하던 옷깃은 수정 후 화면에서
사라졌다. 피부, 손, 회의실 출입구와 가구 배치를 실제 캡처로 확인했다.

다만 상용 FPS 수준의 완성도에 도달했다고 평가하지는 않는다.
의상은 절차적 단면 메시이며 팔꿈치/무릎은 분리 관절이어서 스킨드 의상처럼
변형되지 않는다. 손가락과 소품의 정확한 접촉 IK는 없으며, 표정 변화는
제한적이다. 사무실 업무 구역의 반복과 단순한 가구 모서리도 남아 있다.
적들끼리의 군중 충돌, 가구 위 점프, 모션 캡처는 구현하지 않았다.
